# Contributing

Small, focused pull requests are welcome. Before opening one:

1. Use Node.js 18 or newer.
2. Run `npm test` and `npm run check`.
3. Run `npm run demo` and verify the dashboard and status page in a browser.
4. Never commit provider keys, customer keys, session cookies or `.env` files.

Please explain the user-facing behavior of a change and add a focused test when
it changes analytics, health classification, URL handling or proxy behavior.
